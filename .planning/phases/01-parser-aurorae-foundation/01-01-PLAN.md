The frozen `Theme` dataclass is the single seam between the analyze-half
and generate-half of the pipeline. It must be importable as
`from themey.ir import Theme`. Sub-records below are the minimum shape
referenced by Plans 02–09.

```python
# src/themey/ir.py
from dataclasses import dataclass, field
from pathlib import Path

@dataclass(frozen=True)
class Palette:
    titlebar_active: tuple[int, int, int]      # RGB 0-255
    titlebar_inactive: tuple[int, int, int]
    text_active: tuple[int, int, int]
    text_inactive: tuple[int, int, int]

@dataclass(frozen=True)
class IClassSpec:
    name: str                          # e.g. "TITLE_BAR_HORIZONTAL"
    edge_scaling: tuple[int, int, int, int]   # (left, right, top, bottom)
    normal: Path | None                # path under asset_root, may be None
    normal_active: Path | None
    hilited: Path | None
    hilited_active: Path | None
    clicked: Path | None
    clicked_active: Path | None
    normal_sticky: Path | None
    normal_active_sticky: Path | None

@dataclass(frozen=True)
class TClassSpec:
    name: str                          # e.g. "TEXT1"
    fg_normal: tuple[int, int, int] | None      # __FORGROUND_COLOR after __NORMAL
    fg_active: tuple[int, int, int] | None      # __FORGROUND_COLOR after __NORMAL_ACTIVE

@dataclass(frozen=True)
class ButtonPart:
    iclass_name: str
    aclass: str | None                 # null sentinel when E16 source omits __ACLASS
    tl_x_pct: int                      # Q10 fixed-point: 1024 == 100%
    tl_x_abs: int                      # signed; may be negative
    tl_y_pct: int
    tl_y_abs: int
    br_x_pct: int
    br_x_abs: int
    br_y_pct: int
    br_y_abs: int

@dataclass(frozen=True)
class BorderSpec:
    name: str                          # "DEFAULT" only in Phase 1; others SKIPPED
    border_size_left: int
    border_size_right: int
    border_size_top: int
    border_size_bottom: int
    parts: tuple[ButtonPart, ...]

@dataclass(frozen=True)
class Theme:
    name: str                          # slug from filename, e.g. "Aliens"
    display_name: str                  # human label, may equal name
    author: str | None
    scale: int                         # 1, 2, or 3
    asset_root: Path                   # extracted tmpdir; valid only during convert()
    border: BorderSpec
    iclasses: dict[str, IClassSpec]    # by IClass name
    tclasses: dict[str, TClassSpec]
    button_codes: dict[str, str]       # part.iclass_name -> "X"|"A"|"I"|"L"|"S"
    left_buttons: str                  # final Aurorae LeftButtons string, e.g. "XAI"
    right_buttons: str
    palette: Palette
    notes: list[str] = field(default_factory=list)   # ONLY mutable accumulator
    skipped_borders: tuple[str, ...] = ()
```

The `notes: list[str]` field is intentionally mutable and is the ONLY mutable
accumulator on `Theme`. Analyze-stage code appends; report.py and preview.py
read.

       ```python
       """XDG_DATA_HOME-aware install paths.

       All install paths derive from XDG_DATA_HOME (or ~/.local/share if unset).

       """
       from __future__ import annotations

       import os

       def _xdg_data_home() -> Path:
           v = os.environ.get("XDG_DATA_HOME")
       ```

    ```python
    """Shared pytest fixtures.

    fake_home: monkeypatches HOME + XDG_DATA_HOME to a tmp directory so
    install / preview / report paths route into the test's tmp tree.
    Never use pyfakefs — Pillow and tarfile need real files.
    """
    from __future__ import annotations

    from pathlib import Path

    import pytest


    @pytest.fixture
    def fake_home(tmp_path: Path, monkeypatch: pytest.MonkeyPatch) -> Path:
        """Monkeypatch HOME + XDG_DATA_HOME to tmp_path. Returns the home dir.

        Creates `tmp_path/.local/share` so XDG default resolution works even
        when XDG_DATA_HOME is unset.
        """
        monkeypatch.setenv("HOME", str(tmp_path))
        monkeypatch.delenv("XDG_DATA_HOME", raising=False)
        (tmp_path / ".local" / "share").mkdir(parents=True, exist_ok=True)
        return tmp_path
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem write at install path | All write operations route through `paths.aurorae_themes()`; tests monkeypatch HOME so production paths are never touched |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `paths._xdg_data_home()` reads `HOME` env var unsanitized | accept | Single-user local CLI; if attacker controls `HOME`, threat model already broken. Tests use `fake_home` fixture so suite cannot accidentally write to real home. |
| T-01-02 | Information disclosure | `log.setup_logging` could leak env data via DEBUG output | accept | Log format does not include env vars; only logger name + level + message. -v / -vv emit module-level debug, not OS state. |
| T-01-03 | Denial of service | Unbounded `Theme.notes` list growth | accept | Each conversion is one-shot; process exits after writing report. List bounded by source theme size. |
</threat_model>
