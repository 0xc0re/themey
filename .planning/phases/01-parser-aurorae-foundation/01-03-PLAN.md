```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Include:
    path: str          # the path inside the include directive
    is_angle: bool     # True for `<path>`, False for `"path"`
    line: int          # 1-based source line number for error messages

@dataclass(frozen=True)
class KeyVal:
    keyword: str       # e.g. "__EDGE_SCALING", "__NAME", "__ACLASS"
    values: tuple[object, ...]   # parsed values: int|str|None
    line: int

@dataclass(frozen=True)
class Block:
    keyword: str       # e.g. "__BORDER", "__ICLASS", "__BORDER_PART"
    head_values: tuple[object, ...]  # values BEFORE __BGN (e.g. block name)
    children: tuple["AstNode", ...]  # KeyVal | Block | Include
    line: int

AstNode = Block | KeyVal | Include
```

    ```python
    """Tokenizer for E16 cfg files.

    Recognized tokens:
      IDENT   — uppercase identifiers, may begin with __ (e.g. __EDGE_SCALING)
      NUMBER  — signed integers; floats not used in E16 cfg
      STRING  — double-quoted, no escape sequences in E16 source (verified)
      INCLUDE — '#include' keyword
      ANGLE_PATH — <path> after #include
      QUOTED_PATH — "path" after #include
      NEWLINE — line breaks (significant for top_kv termination)

    Skipped: /* ... */ (multi-line C comments) and # ... \n (single-line),
    EXCEPT '#include' which is its own token.
    """
    from __future__ import annotations

    from dataclasses import dataclass
    from enum import Enum


    class TokenKind(Enum):
        IDENT = "IDENT"
        NUMBER = "NUMBER"
        STRING = "STRING"
        INCLUDE = "INCLUDE"
        ANGLE_PATH = "ANGLE_PATH"
        QUOTED_PATH = "QUOTED_PATH"
        NEWLINE = "NEWLINE"
        EOF = "EOF"


    @dataclass(frozen=True)
    class Token:
        kind: TokenKind
        value: object   # str for IDENT/STRING/PATH; int for NUMBER; None for NEWLINE/EOF
        line: int       # 1-based


    def tokenize(text: str) -> list[Token]: ...
    ```

    Implementation notes:
    - Track `line` counter; increment on `\n`.
    - Handle `/* ... */` by scanning forward to next `*/` (multi-line capable); count newlines while skipping.
    - Handle `#` line comments by skipping to next `\n` — BUT first check if the literal next chars are `include ` (with whitespace) — if so, emit `INCLUDE` token and continue lexing the path.
    - After `INCLUDE`, expect either `<` (then read until `>` and emit ANGLE_PATH) or `"` (then read until next `"` and emit QUOTED_PATH).
    - IDENT regex: `[_A-Z][_A-Z0-9]*` (uppercase + underscore + digits; E16 idents are all-caps).
    - NUMBER regex: `-?[0-9]+`.
    - STRING regex: `"([^"]*)"` — no escape sequences in E16 (verified per 01-RESEARCH.md grammar sketch).
    - NEWLINE token only emitted between non-skipped tokens (parser uses it to terminate `top_kv` lines).
    - EOF token at end.

    ```python
    """Recursive-descent parser for E16 cfg files.

    Generic-block-store: any keyword followed by __BGN ... __END forms a Block;
    keys not starting a block form KeyVal lines. Unknown keywords do NOT raise —
    the analyze layer in src/themey/analyze/ picks the blocks it understands.

    `#include <definitions>` is silently skipped (E16's built-in macro file is
    not shipped in .etheme archives). Other includes are resolved relative to
    asset_root.
    """
    from __future__ import annotations

    from pathlib import Path

    from .ast import AstNode, Block, Include, KeyVal
    from .lex import Token, TokenKind, tokenize


    class ParseError(Exception):
        """Raised on truly broken input (mismatched __BGN/__END, etc.)."""


    def parse_file(path: Path) -> list[AstNode]:
        text = path.read_text(encoding="utf-8", errors="replace")
        tokens = tokenize(text)
        return _Parser(tokens, source=str(path)).parse_program()


    def parse_tree(asset_root: Path,
                   entry_files: list[str] | None = None) -> list[AstNode]:
        """Parse all entry files; resolve #include directives by inlining."""
        if entry_files is None:
            entry_files = ["borders.cfg", "imageclasses.cfg", "textclasses.cfg"]
        seen: set[Path] = set()
        nodes: list[AstNode] = []
        for entry in entry_files:
            p = asset_root / entry
            if p.is_file():
                nodes.extend(_parse_with_includes(p, asset_root, seen))
        return nodes


    def _parse_with_includes(path: Path, root: Path,
                             seen: set[Path]) -> list[AstNode]:
        rp = path.resolve()
        if rp in seen:
            return []  # cycle guard
        seen.add(rp)
        out: list[AstNode] = []
        for node in parse_file(path):
            if isinstance(node, Include):
                if node.is_angle and node.path == "definitions":
                    continue   # silently skip built-in macro file
                target = (path.parent / node.path).resolve()
                if not str(target).startswith(str(root.resolve())):
                    # include escapes the asset root — treat as missing
                    continue
                if target.is_file():
                    out.extend(_parse_with_includes(target, root, seen))
                # else: silently drop (some legacy themes have stale includes)
            else:
                out.append(node)
        return out


    class _Parser:
        # Implements the BNF in 01-RESEARCH.md Pattern 1:
        # file := (toplevel)*
        # toplevel := include | block | top_kv
        # block := keyword '__BGN' (statement)* '__END'
        # statement := keyword (value)+ NEWLINE | block
        # value := IDENT | INTEGER | STRING
        ...
    ```

    Implementation rules for the `_Parser` class:
    - Maintain `self.pos` index into tokens.
    - `parse_program()` loops calling `parse_toplevel()` until EOF.
    - `parse_toplevel()`: if INCLUDE → consume, then ANGLE_PATH or QUOTED_PATH → emit Include. If IDENT → look ahead: if next non-NEWLINE token is IDENT == "__BGN" or this IDENT followed by IDENTs followed by `__BGN` then it's a Block; else it's a top_kv KeyVal terminated by NEWLINE.
    - `parse_block()`: consume head IDENT + head values (IDENTs/NUMBERs/STRINGs before `__BGN`); consume `__BGN`; loop calling `parse_statement()` until `__END`; consume `__END`.
    - `parse_statement()`: same dispatch as toplevel (statements can be nested blocks).
    - On `__END` with no matching `__BGN`: raise `ParseError(f"unexpected __END at line {tok.line} in {self.source}")`.
    - Skip stray NEWLINE tokens between toplevel/statement productions.

    The "head values" of a block matter for `__BORDER DEFAULT __BGN ... __END` (Block.keyword="__BORDER", Block.head_values=("DEFAULT",)) and `__BORDER_PART __BGN ... __END` (head_values=()) and `__ICLASS TITLE_BAR_HORIZONTAL __BGN` (head_values=("TITLE_BAR_HORIZONTAL",)) and `__TCLASS TEXT1 __BGN` (head_values=("TEXT1",)).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| extracted asset_root → parser | Parser reads files from a tmpdir already validated by safe_extract. Trust assumption: only regular files inside dest, all symlinks resolved to bytes. |
| `#include` path → asset_root | Include paths come from cfg text — adversary could craft a cfg with `#include "../../etc/passwd"` IF they bypassed safe_extract. |

|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `#include "../../escape"` reads file outside asset_root | mitigate | `_parse_with_includes` resolves the include target and rejects (silently drops) if not under `root.resolve()`; same path-prefix check pattern as safe_extract |

| T-03-03 | DoS | malformed cfg with millions of nested __BGN never closed | accept | Parser raises `ParseError` on EOF inside an unclosed block; no recursion limit issue at typical theme depth (≤ 3 levels) |
