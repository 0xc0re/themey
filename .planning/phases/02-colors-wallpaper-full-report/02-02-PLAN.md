@dataclass(frozen=True)
class Block:

    line: int

```python
def select_wallpaper(
    ast_nodes: list[AstNode],
    asset_root: Path,
    iclasses: dict[str, IClassSpec],
) -> WallpaperSpec | None:
    """Select the desktop wallpaper from parsed AST.

    Walks BOTH __DESKTOP (Form 1) and __BACKGROUND (Form 2) top-level blocks.
    Returns the first candidate in source order with an existing on-disk image;
    other candidates' labels go into skipped_alternatives.

    Args:
        ast_nodes: Top-level AST nodes from parse.parse_file() or parse_tree().
                   Includes/non-blocks are tolerated and skipped.
        asset_root: Absolute path to the extracted theme root. Every cfg file
                    path is resolved relative to this and prefix-checked
                    (T-05-01 mitigation).
        iclasses: Name -> IClassSpec from build_iclasses; used to resolve
                  Form-2 __BG_BG iclass references to actual PNG paths.

    Returns:
        WallpaperSpec for the chosen background, or None if no candidates
        resolve to an existing on-disk image. Caller decides solid-only
        fallback or fallback to titlebar PNG (Wave 3).
    """
```

Implementation walks `ast_nodes` once collecting `(image_path, fit, solid, label)` candidates. The walker must:
- Filter to `Block` instances only.
- For `block.keyword == "__DESKTOP"`:
  - Read `__NAME` from children for the label (use `_block_name`).
  - Read the FIRST `__SOLID_COLOR` KeyVal child for `solid`.
  - Iterate children for `__BACKGROUND_LAYER` KeyVals. Each KeyVal.values is `(file, tile, keepaspect, xjust, yjust, xperc, yperc)`. Take the FIRST __BACKGROUND_LAYER per __DESKTOP (RESEARCH §4 Step 2: one image per desktop).
  - Build `(asset_root / file_rel).resolve()` and apply the path-traversal prefix check from `analyze/iclasses.py:79, 102-108`. If the path escapes asset_root or `.is_file()` is False, skip this candidate.
  - On accept: append `(abs_path, fit, solid, label)` to candidates, then `break` out of the layer loop for this desktop.
- For `block.keyword == "__BACKGROUND"`:
  - Read `__NAME` for the label (via `_block_name`).
  - Read the first `__BG_SOLID` for solid.
  - Read the first `__BG_BG` KeyVal. KeyVal.values is `(iclass_name, tile, keepaspect, xjust, yjust, xperc, yperc)`. Look up `iclasses[iclass_name]`; if present and `.normal` is non-None and `.normal.is_file()`, accept candidate.
- After the walk: if candidates empty → return None. Otherwise pick `candidates[0]` and emit `WallpaperSpec(image_path=chosen[0], fit_mode=chosen[1], solid_color=chosen[2], desktop_label=chosen[3], skipped_alternatives=tuple(c[3] for c in candidates[1:] if c[3] is not None))`.

Path-traversal helper (factor into a private `_safe_under(root: Path, candidate: Path) -> bool`) for code reuse:
```python
def _safe_under(asset_root: Path, candidate: Path) -> bool:
    """Return True iff candidate.resolve() is asset_root or strictly inside it.

    Mirror of the prefix-check pattern in analyze/iclasses.py:102-108
    (T-05-01 mitigation). Use for every file path read from cfg.
    """
    asset_root_resolved = str(asset_root.resolve())
    candidate_resolved = str(candidate.resolve())
    return (
        candidate_resolved == asset_root_resolved
        or candidate_resolved.startswith(asset_root_resolved + "/")
    )
```

Implement `extract_dominant(image_path: Path, k: int = 8) -> list[WeightedColor]` per RESEARCH Code Examples lines 1047-1061. Key steps:
1. `img = Image.open(image_path).convert("RGBA")`
2. `bg = Image.new("RGBA", img.size, (128, 128, 128, 255))` — neutral grey backdrop
3. `opaque = Image.alpha_composite(bg, img).convert("RGB")` — Pitfall B mitigation
